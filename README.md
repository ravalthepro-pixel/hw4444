# AI 100 - HW4: Interacting with an LLM via Code
Author: Jay Raval

## What this does
Uses the Groq API to interact with an open-source LLM (Llama 3.1) through code
and inspect the outputs across 3 different inputs.

## How to run
1. Install the dependency: pip install groq
2. Add your Groq API key where it says YOUR_KEY_HERE
3. Run: python llm_api_experiments.py

## Experiments
- Question 1: What is machine learning?
- Question 2: Real world examples of machine learning
- Question 3: Supervised vs unsupervised learning
